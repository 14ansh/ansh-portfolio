# Ansh Jain — Premium Portfolio

## Publish on GitHub Pages
1. Create a public GitHub repository named `ansh-portfolio`.
2. Upload `index.html` and the `assets` folder.
3. Go to Settings → Pages.
4. Select Deploy from branch → `main` → `/ (root)`.
5. Save and wait for GitHub to publish it.
6. Your portfolio will be available at:
   `https://14ansh.github.io/ansh-portfolio/`

Add the published URL to LinkedIn → Contact info and Featured.
